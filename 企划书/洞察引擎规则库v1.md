# 洞察引擎规则库 v2（锚定真实字段）

> v1 引用了财务三表/税负率/TOP10 等**数据里不存在的字段**，违反"不幻觉"原则。v2 全部锚定当前真实字段：
> `CoreMetrics`（匿名税务宽表）+ `EnterpriseEngineFeatures`（发票/真实性引擎特征）+ `LegalEvent`。
> 阈值标 `⚠待校准` 的是初值，需用真实数据回算。

## 数据字段可用性（真实）

| 域 | 可用字段 |
|---|---|
| 税务 | credit_score、credit_level、tax_on_time_rate、tax_arrears_cnt、tax_violation_cnt、high_severity_cnt |
| 司法 | is_dishonesty、is_execution、loan_cnt、loan_amount、LegalEvent(event_type/severity/amount) |
| 发票舞弊 | fraud_composite_score、fraud_risk_level、fraud_signals、scbm_mismatch_score、red_invoice_score、concentration_score、sequence_gap_ratio、pyod_score |
| 真实性 | authenticity_score、cross_avg_deviation、cross_suspicious、revenue_deviation、vat/invoice/finance_revenue |
| 财务（四能力） | current_ratio、quick_ratio、gross_margin、net_margin、roe、roa、receivables_turnover、inventory_turnover、asset_turnover、has_financial_statements（由三大报表 ETL 计算） |
| 财务（代理） | debt_ratio、cash_flow_net、cash_flow_level、profit_margin、revenue_yoy、profit_yoy（无三大报表样本回退） |
| 发票画像（Phase 2） | customer_concentration、supplier_concentration、category_concentration（CoreMetrics 标量）；EnterpriseInvoiceProfile：进销规模、红字/作废/异常、TOP5 客户/供应商（税号脱敏）、TOP5 品目、单价分布 |
| 税务画像（Phase 3） | vat_burden、income_tax_burden、correction_times、social_headcount、tax_late_penalty_cnt（CoreMetrics 标量）；EnterpriseTaxProfile：完税、滞纳金罚款、更正、社保、银税互动、优惠/研发/高新/股权/变更 |

> ✅ **现已抽取**（Phase 1 财务扩容）：三大报表 216 行项目 → EnterpriseFinancials + 四能力比率（偿债/营运/盈利/成长），163/193 家有完整报表。
> ✅ **现已抽取**（Phase 2/3 发票+税务画像）：客户/供应商/品目集中度、税负率、申报更正、滞纳金罚款、社保、银税互动、优惠研发、股权变更 → EnterpriseInvoiceProfile + EnterpriseTaxProfile（193 家全覆盖）。对手方名称源库已脱敏（MD5），无明文 PII。

|---|---|

**校准结论**：
- Phase 2/3 新增 8 条规则阈值经真实数据回算，命中率落在 3%~43%，区分度良好（高危 I-08 仅 10.4%、T-06/T-08 为离群信号）。
- 存量规则（真实性 A-01/A-02/A-03、财务 F-01、税务 T-04）命中面仍偏宽，导致"每家都有洞察"、区分度不足。下一步需在报告层按 `severity` 排序 + 只展示 Top-N（如高危全量 + 预警 Top3），并视用户对"选择性"的偏好回算存量阈值。
- T-06 更正阈值 80 基于分布离群值（中位数 52、p95=64、max=195），申报更正数据本身接近全量采集，非强区分字段，报告中宜以"离群值"口径呈现而非绝对次数。

## 二、下一轮采集验证

样本建议：

```text
10 家公司
3 年
年度 / 半年度 / 季度报告
业绩预告 / 业绩快报
```

| 指标 | 建议门槛 |

| 元数据查询成功率 | >= 98% |

| 人工复核耗时 | 持续下降 |

## 四、预测模型验收

预测必须先有可靠标签和时间切分，至少报告：

- AUC / PR-AUC。
- Brier Score 或概率校准曲线。
- 召回率和误报率。
- 按时间切分的回测。
- 分行业、分年份稳定性。
- 数据漂移和模型衰减。
- SHAP 或等价的特征贡献解释。
- 数据泄漏检查。

禁止使用随机切分替代时间切分。

## 五、进入生产 Domain Pack 的条件

只有同时满足以下条件，才能接入现有主引擎：

1. 采集流水线可重复运行。
2. 字段存在来源 URL、文件哈希、页码和原文片段。
3. 核心字段通过会计恒等式和多来源交叉校验。
4. 事件候选具备适用性判断，不把关键词直接当风险结论。
5. 指标、阈值、维度和报告章节已形成 Domain Pack。
6. 所有输出可转换为 Claim，并能被 RAG 和报告 Block 复用。

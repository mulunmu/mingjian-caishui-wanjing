# 数据采集模块设计与验收

## 一、模块定位

数据采集模块是 Domain Pack 的前置基础设施，不是一次性的 PDF 下载脚本。

```text
Source Registry
-> Discovery
-> Download
-> Parse
-> Extract
-> Event Extraction
-> Validate
-> Store
-> Schedule
-> Claim / RAG / Report
```

## 三、解析与抽取策略

优先级：

```text
XBRL / 结构化 HTML
-> 原生 PDF 文本和表格
-> OCR
```

工具组合：

- `pdfplumber`：文本和表格。
- `PyMuPDF`：页面坐标和文本定位。
- `Docling`：文档结构和版面。
- `MinerU`：复杂 PDF 版面。
- `PaddleOCR` / Tesseract：扫描件。
- `Pydantic`：Schema 校验。

原则：

```text
先结构和规则
再表格解析
最后 LLM 补足
所有字段保留证据位置
```

## 四、数据校验

### 数值层

- 类型、单位和币种。
- 合法范围和精度。
- 括号负数、千分位和百分比。

### 会计层

- 资产 = 负债 + 所有者权益。
- 收入、成本、利润勾稽关系。
- 现金流与资产负债表、利润表的关联。

### 时间层

- 同比和环比。
- 突变和连续性。
- 报告期与公告发布时间一致性。

### 来源层

- 多来源交叉验证。
- URL、文件哈希、页码和原文片段完整。
- 解析器和 Schema 版本可追溯。

## 五、验收门禁

### Gate 1：单公司

- PDF 可下载。
- 文本和表格可解析。
- 5 个以上核心字段可抽取。
- 字段有页码证据。

### Gate 2：10 家公司 × 3 年

- 下载成功率 >= 95%。
- 核心字段抽取准确率 >= 95%。
- 字段证据覆盖率 100%。
- 会计恒等式通过率 >= 98%。

### Gate 3：50 家公司

- 跨模板解析稳定。
- 跨页表格、单位和负数处理稳定。
- 增量更新和断点续传可用。

### Gate 4：500 家公司 × 3 年

- 任务调度和限速稳定。
- 存储、重放和质量看板可用。
- 失败任务可定位、可重试、可审计。

## 六、验收产物

- 来源注册表。
- 采集任务运行记录。
- 文件清单和哈希。
- 标准化财务事实表。
- 披露事件表。
- 字段证据索引。
- 质量报告和失败清单。
- 采集回放报告。

## 七、禁止事项

- 不绕过验证码、付费墙和访问控制。
- 不将关键词命中直接判断为风险成立。
- 不将 LLM 输出作为唯一财务事实来源。
- 不允许没有来源和页码的数字进入 Claim。
- 不在采集契约未冻结前扩大全市场抓取。

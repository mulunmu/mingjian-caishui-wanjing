# 阶段 20 金融模型闭环报告

日期：2026-09-17

候选标签：`rag-v2-stage20-accepted-20260917`

## 一、结论

阶段 20 已建立异步、可配置、可评测的金融复核层，并完成 API baseline 评测和本地部署决策。API baseline 通过质量测试，但由于延迟过高，默认不进入每轮必经路径；当前机器也不批准本地生产部署。

## 二、实现

- 新增 `financial_model.py`：统一解析 `FINANCIAL_LLM_*`，并支持回退到主 LLM 作为 API baseline。
- `generate_financial_interpretation` 已改为异步 Instructor JSON 路径，不再阻塞事件循环。
- 金融复核只能使用已有 Claims，输出不得包含任何数字。
- `finance_review_agent` 在模型不可用时明确 skip，在不启用时不改变主回答。
- readiness 输出金融模型的非敏感配置状态，不暴露 API Key。

## 三、API Baseline 评测

配置：

```text
model=deepseek-v4-pro
source=main_api_baseline
provider=openai_compatible
```

评测结果：

```text
total=10
passed=10
failed=0
pass_rate=1.0
digit_leakage=0
P50=4996.26ms
P95=8945.87ms
```

评测覆盖资产负债、现金流、盈利、增值税、欠税、红票、客户/供应商集中、存货周转和口径偏差。

结论：质量门禁通过，延迟门禁不通过，因此：

```text
LANGGRAPH_FINANCE_REVIEW_ENABLED=false
```

它适合报告生成后的异步复核、离线复核或后续本地低延迟模型，不适合普通对话每轮同步调用。

# 阶段 9H：退役审计与章节清理

日期：2026-09-16

## 结论

无引用的章节兼容层已经清理，但旧对话入口尚不能删除。

```text
safe_to_retire=false
shadow_gate_passed=true
remaining_blockers=legacy_markers_remain, legacy_entrypoint_still_active
```

原因是生产语义主路径尚未接管，`route_chat` 和软降级正则仍然是真实故障链路的一部分。
此时删除它们会形成未经验证的单点故障，不符合红线要求。

## 已完成的清理

- 删除 `CUSTOM_CHAPTERS`、`CUSTOM_CHAPTER_DIMENSIONS`、`FUNCTION_RADAR_DIMENSIONS`。
- 所有内部调用统一使用 `CHAPTER_REGISTRY`。
- 所有章节键都能归一化到 `loan | rating | warn | audit`。
- 新增可执行退役审计 CLI：`backend/scripts/audit_legacy_retirement.py`。
- 新增防回归测试，禁止章节兼容别名和生产代码残留。

## 发现并修复

匿名 staging 的固定报告向导曾出现两个根因问题：

1. `authenticity` 章节键没有映射到 canonical 场景，导致 500。
2. 非法客户端场景也被错误转换为 500。

修复后：

```text
authenticity -> audit, ok=true, available_chapters=4
unknown scenario -> HTTP 422
```

报告 Action Title 中还存在一个硬编码禁词“权重”，会阻断 PDF 预检。现已改为
“结构变化 / 结构分布”，并新增覆盖全部章节 Action Title 的报告禁词回归测试。

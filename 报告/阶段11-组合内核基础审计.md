## 已完成能力

### 类型化组合 IR

新增 `ModuleSpec`、`PortSpec`、`CompositionNode`、`CompositionEdge`、
`CompositionPlan` 和验证报告。

校验内容覆盖：

- 模块存在性和 executable 状态。
- 必填输入绑定。
- 输入输出端口类型匹配。
- DAG 环路检测。
- 输出节点存在性。
- 计划节点数量上限。

### 异步 DAG 运行时

新增有界异步执行器，支持：

- 无依赖节点并发执行。
- 依赖节点等待上游输出。
- `Semaphore` 并发上限。
- 节点超时。
- 重试和 fallback handler。
- 节点级结果和执行顺序记录。

### 组合规划器

已实现以下模式：

```text
metric_lookup
metric_threshold
metric_threshold_compare
trend_then_drilldown
report_chapter
```

规划器只生成 DAG，不执行；禁用或非 validated 模块不会被选中。

### 模块目录

目录从内置算子、知识模块、验证器、报告块、指标、阈值和章节构建，并支持
从现有 Tool Snapshot 补充 validated 工具。当前测试确认目录不少于 60 个模块。

### Semantic Frame

已增加结构化语义帧，包含：

```text
policy_route
speech_act
business_domain
task_type
subject_scope
entities
metrics
filters
output_requirements
references
language
safety
missing_slots
confidence
```

primary 响应现在携带 `data.primary.semantic_frame`。

### 多指标异步执行桥

新增 `composition_execution_bridge`：

- 从 Semantic Frame 提取多个指标。
- 只选择 validated 且可执行的 metric 模块。
- 构建 `plan-multi-metric-*` DAG。
- 每个节点使用独立 AsyncSession，避免并发复用同一会话。
- 通过 `AsyncDagRuntime` 并行执行独立指标节点。
- 合并 Claims 和 follow-ups。
- 统一经过叙述层和幻觉闸门。

primary 响应新增：

```text
composition_plan_id
composition_elapsed_ms
composition_completed_order
composition_cache_hits
composition_failed_nodes
```

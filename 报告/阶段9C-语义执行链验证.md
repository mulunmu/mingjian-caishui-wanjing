# 阶段 9C：语义执行链验证

日期：2026-09-16

## 实现

- ToolPlan 支持异步工具调用。
- 已验证数值指标可以转换为 `SemanticQuery`。
- 指标执行委托给现有 `judgment_service.run_semantic_query`。
- 扩展 `CoreMetrics` 数值字段到执行层映射。
- Tool RAG 支持 `executable_only` 候选过滤。
- 没有执行器的 validated 工具不会进入 canary 候选。

## 安全边界

- 执行器只返回 `Claim`。
- 数字仍然由确定性引擎生成。
- 未注册执行器的工具会被明确拒绝。
- 非法计划在执行前被拒绝。
- 生产主路径仍未切换。

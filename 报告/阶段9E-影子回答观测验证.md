# Stage 9E: Shadow Answer Observation

Date: 2026-09-16

## Implemented

- Shadow mode can run the semantic answer composer.
- Observations are stored with only a query digest, not raw user text.
- Recorded fields:
  - status
  - route and domain
  - candidate tool IDs
  - plan tool IDs
  - claim count
  - reply presence
  - latency
  - error
- Combined release gate now includes answer-level evidence.

## Answer Gate

Required before canary:

- at least 20 answer observations
- answer rate >= 60%
- reply-present rate >= 80%
- error rate <= 5%

`planned` tools must still remain disabled.

## Configuration

Pre-release only:

```env
SHADOW_SEMANTIC_ENABLED=true
SHADOW_SEMANTIC_INDEPENDENT_ROUTE=true
SHADOW_ANSWER_EVAL_ENABLED=true
```

Production defaults:

```env
SHADOW_SEMANTIC_ENABLED=false
SHADOW_ANSWER_EVAL_ENABLED=false
```

## Safety

- Answer evaluation remains post-response and default-off.
- Shadow failures never alter the legacy response.
- No production traffic is switched by this stage.

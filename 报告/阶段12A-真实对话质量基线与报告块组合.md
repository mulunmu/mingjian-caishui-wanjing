超纲、拒编、脏话、多语言、未知企业、澄清和六轮 N-2 记忆。


本轮不是只修单句，已修复以下类别：

- 同业位置和优先核查问题增加可执行工具与 RAG 别名。
- “能问哪些指标/能否多指标分析”走确定性能力路由。
- 垃圾、废物、滚动、蠢、答非所问等攻击表达统一走降温策略。
- 英文财税请求在域内时进入 language_switch，不再误判超纲。
- 不存在企业、无此企业等表达进入 unknown_entity。
- 短指代和乱码进入 clarify，不再误判域外问题。
- 长 session_id 的 topic_id 自动压缩到 VARCHAR(64) 以内。

## 报告块级组合

调研结论与实现方式：

- knitr 的动态报告模式把每一段代码块、数据、输出作为一个可复用单元。
- QuestPDF 等文档库使用 Fluent/Block 结构组合页面，而不是生成一整段字符串。
- Jinja2 + WeasyPrint 适合作为本项目渲染层，但中间必须先有结构化报告块 AST。

参考：

- https://github.com/yihui/knitr
- https://github.com/QuestPDF/QuestPDF
- https://github.com/CERT-Polska/Artemis
- https://doc.courtbouillon.org/weasyprint/stable/

当前实现：

```text
章节
-> 指标 Claim 段落块
-> 章节综合研判块
-> PDF / 报告详情 / 前端报告页
```

真实四章节报告验证：

```text
title=财务健康·税务合规·发票舞弊·经营真实性 定制风控报告
chapters=4
block_counts=14,4,6,3
email_status=sent
pdf_magic=%PDF-
pdf_bytes=220213
```

全量回归：

```text
1247 passed, 7 skipped, 0 failed
```

用户可见 PDF/HTML 不展示 `core_metrics` 等内部溯源字段；结构化 API 继续保留
完整 trace。报告仍由指标、阈值和 Claim 组合，不存在 LLM 直接生成整篇报告。

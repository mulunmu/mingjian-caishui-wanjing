# 阶段 20 本地金融模型部署评估

日期：2026-09-17

## 一、当前硬件

```text
GPU：NVIDIA GeForce RTX 4060 Laptop GPU
显存：8GB
系统内存：约 16GB
D 盘可用：约 424GB
CUDA 驱动：12.7
```

## 二、候选模型

### DISC-FinLLM

来源：

```text
FudanDISC/DISC-FinLLM
license=Apache-2.0
base=Baichuan-13B-Chat + LoRA
```

模型权重总大小约 `24.7GB`（FP16）。4-bit 后权重约 7GB，但加上 KV cache、推理运行时和系统占用，在 8GB 显存上没有安全生产余量。16GB 系统内存也不适合生产并发。

结论：当前机器不适合生产部署。

### XuanYuan-6B-Chat-4bit

来源：

```text
Duxiaoman-DI/XuanYuan-6B-Chat-4bit
license=Llama-2
quantization=GPTQ 4bit
主权重约 3.55GB
```

权重本身可以放入 8GB 显存，但它仍需要 GPTQ 运行时、KV cache 和额外内存。当前机器仅适合离线功能验证，不适合生产 SLA。

结论：可作为下一轮本地 PoC 候选，但不能直接作为生产模型。

### FinGPT / Llama 候选

来源：

```text
AI4Finance-Foundation/FinGPT
license=MIT（代码）
```

FinGPT 更偏英文金融情绪、新闻和交易场景，模型许可证还会继承具体 Llama 基座限制。与当前中国财税票风控场景的直接匹配度低于 DISC-FinLLM 和轩辕。

结论：不作为当前首选。

## 三、部署决策

```text
当前机器本地生产部署：不批准
当前机器本地 PoC：可尝试 XuanYuan-6B-Chat-4bit
推荐生产本地硬件：24GB 以上显存、32GB 以上内存
当前生产策略：使用 API baseline 评测，默认不启用每轮金融复核
```

不能用 70B/176B 模型在当前机器部署。13B 4-bit 也不应压到 8GB 显存边界上运行。

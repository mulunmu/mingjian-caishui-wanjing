# 阶段 9B：综合发布门禁验证

日期：2026-09-16

## 实现

- 综合检查 Registry 就绪状态。
- 综合检查影子评估样本和质量门槛。
- 输出唯一裁决：
  - `stay_on_legacy`
  - `ready_for_canary`
- 提供可执行命令：
  - `python -m scripts.deployment_gate --min-samples 20`

## 门禁条件

进入 canary 必须同时满足：

- 9 张语义与影子表存在。
- 已验证指标、工具和阈值达到最低数量。
- `planned` 工具全部保持禁用。
- 影子样本数达到 20。
- 路由匹配率不低于 95%。
- 业务域匹配率不低于 95%。
- 平均工具覆盖率不低于 75%。
- switch-eligible 比例不低于 80%。

## PostgreSQL 验证

在一次性 PostgreSQL 16 上执行：

```text
python -m scripts.verify_semantic_readiness --apply
python -m scripts.deployment_gate --min-samples 20
```

结果：

```text
decision=stay_on_legacy
exit_code=1
```

这是正确行为：数据库已就绪，但没有影子样本，不允许 canary。

## 安全结论

- 未切换生产流量。
- 未删除旧路径。
- 未伪造影子样本。
- 只有真实积累样本并通过门禁后，才能进入下一阶段。
